

# Assistente Guida Colore per Photoshop


Uno script ExtendScript (.jsx) per Adobe Photoshop pensato per velocizzare la creazione di guide colore durante la produzione di animazioni, illustrazioni e progetti grafici.

Lo script genera automaticamente una guida colore completa a partire dal colore di primo piano selezionato, organizzando tutti gli elementi in un unico gruppo di livelli.

Funzionalità
🎨 Crea automaticamente un campione del colore selezionato.
📝 Inserisce il nome del colore.
🔢 Mostra i valori RGB.
📌 Permette di aggiungere una nota opzionale.
💯 Permette di indicare l'opacità del colore.
📂 Organizza tutti gli elementi in un gruppo di livelli dedicato.
📺 Controlla che il colore rientri nei valori TV Safe, avvisando se uno dei canali RGB è inferiore a 10 o superiore a 245.
Perché nasce questo script?

Durante la produzione di una serie animata è necessario creare decine (o centinaia) di guide colore per personaggi, oggetti e ambientazioni. Realizzarle manualmente richiede tempo ed è facile commettere errori.

Questo script automatizza il processo, mantenendo tutte le guide uniformi e riducendo il rischio di utilizzare colori non adatti alla trasmissione televisiva.

Supporto agli script ExtendScript (.jsx)
Utilizzo:
- Seleziona il colore desiderato come colore di primo piano.
- Esegui lo script.
- Scegli quali elementi vuoi creare:
     Guida colore
     Valori RGB
     Nome del colore
     Note
     Opacità
- Premi OK.

Lo script creerà automaticamente una guida colore completa e organizzata all'interno di un gruppo di livelli.
