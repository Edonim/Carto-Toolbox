Batch Appiattisci Gruppi BG

Uno script ExtendScript (.jsx) per Adobe Photoshop che elabora automaticamente intere cartelle di file PSD e PSB, appiattendo tutti i gruppi contenuti nelle cartelle chiamate "BG".

Lo script è pensato per pipeline di produzione in cui è necessario ottimizzare o preparare grandi quantità di file senza intervenire manualmente su ciascun documento.

Funzionalità
📂 Elabora automaticamente tutti i file PSD e PSB presenti in una cartella.
🔄 Supporta l'elaborazione ricorsiva delle sottocartelle.
🗂 Cerca automaticamente tutti i gruppi chiamati "BG" (anche annidati).
🖼 Appiattisce i sottogruppi presenti all'interno di ogni gruppo BG, preservando il resto della struttura del documento.
🔓 Sblocca automaticamente livelli e gruppi bloccati prima dell'appiattimento.
💾 Salva i file elaborati in una cartella di output separata.
📝 Possibilità di aggiungere il suffisso _MG ai file generati per evitare sovrascritture.
📊 Barra di avanzamento durante l'elaborazione.
✅ Report finale con numero di file elaborati, saltati ed eventuali errori.
Perché nasce questo script?

Durante la produzione di serie animate o progetti con molti fondali, è frequente avere centinaia di file PSD organizzati con una cartella BG contenente numerosi gruppi di livelli.

Appiattire manualmente questi gruppi è un'operazione lunga, ripetitiva e soggetta a errori. Questo script automatizza l'intero processo, riducendo drasticamente i tempi di lavorazione e mantenendo una struttura coerente dei file.

Requisiti
Adobe Photoshop CS6 o versioni successive.
Supporto agli script ExtendScript (.jsx).
Utilizzo
Avvia lo script in Photoshop.
Seleziona la cartella contenente i file PSD/PSB.
Scegli la cartella di destinazione.
Decidi se:
elaborare anche le sottocartelle;
aggiungere il suffisso _MG ai file esportati.
Premi Avvia.

Lo script elaborerà automaticamente tutti i file trovati, mostrando una barra di avanzamento e un riepilogo finale dell'operazione.
